# Relayout

Relayout is a Mac app that fixes text typed in the wrong keyboard layout with one
keystroke, for every layout macOS ships, including Hebrew, Arabic and Thai. It acts only
when you press the shortcut, never on its own, and is sold only on the Mac App Store.

- Website: https://relayoutapp.com
- Mac App Store: https://apps.apple.com/app/id6807043461
- Support: support@relayoutapp.com

This repository only forwards its old GitHub Pages address to relayoutapp.com. Relayout's
source is not public, it is not on Homebrew, it has no Windows version yet, and it is not
the free open-source project reLayout, which is a different app by a different developer.
